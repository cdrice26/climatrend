# Climatrend
This is a webpage that allows the user to request historical weather information and see it graphed, along with a long-term forecast. You can view multiple metrics or even compare locations if you like.

# Disclaimer
This app is in development. Bugs and inaccuracies may occur. Please use with caution, and note that the software is provided as-is and without assumption of correctness.

# Installation and Usage
This is an R Shiny app, so the easiest way is to just install the required packages and run the app in RStudio.
